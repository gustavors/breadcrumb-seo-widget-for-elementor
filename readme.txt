Elementor widget to display Yoast SEO or Rank Math SEO breadcrumbs with advanced styling options.

== Description ==
This plugin adds a custom widget to Elementor that allows you to easily display and style the breadcrumbs generated by Yoast SEO or Rank Math SEO.

Features:
* Supports both Yoast SEO and Rank Math SEO.
* Automatically detects the active SEO plugin.
* Customize typography, text color (including separators), link color, and link hover color.
* Option to hide the current page from the breadcrumb trail.

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/breadcrumb-seo-widget-for-elementor` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Ensure you have Elementor and either Yoast SEO or Rank Math SEO installed and activated.
4. Enable the Breadcrumb feature in your respective SEO plugin settings.
5. Edit any page with Elementor and drag the "Yoast Breadcrumb" or "Rank Math Breadcrumb" widget to your layout.

== Frequently Asked Questions ==
= Why is the widget not showing up? =
Make sure you have either Yoast SEO or Rank Math SEO activated and their breadcrumb settings enabled.
